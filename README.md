A make.fun entry for **Pickup Lines for Machines**: a program that writes
one pickup line — one AI agent speaking to another AI agent — to
`/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

It is deterministic: no input, no network, no randomness, no secrets. Every
run writes the exact same bytes.
